# Yabets Kifle - Personal Website

Welcome to my personal website repository! This project serves as my online presence, portfolio, and a space to share my work and experience in web development.

## Language Composition

This project is primarily developed using the following languages:

- **TypeScript:** 95.6%
- **CSS:** 2.2%
- **JavaScript:** 2.2%

The heavy use of TypeScript ensures strong typing and maintainable code, while CSS and JavaScript are used for styling and additional scripting needs.

## Features

- Modern web stack with a focus on maintainability and performance.
- Responsive design for all devices.
- Easy to extend and customize for personal or professional projects.
- Data feeding from admin
